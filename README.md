# 러브컨츄리

뜨개 DIY 키트 브랜드 **러브컨츄리**의 반응형 한국어 홈페이지입니다.

## 실행

빌드 도구가 필요 없습니다. `index.html`을 브라우저에서 열거나 간단한 정적 서버로 확인하세요.

```sh
python3 -m http.server 8000
```

## 구성

- `index.html` — 홈, 소개, 제품, 이야기, 연락 섹션
- `styles.css` — 반응형 디자인과 접근성 스타일
- `script.js` — 모바일 메뉴, 스크롤 효과, 제품 필터, 문의 폼
- `assets/` — 사이트 이미지

> 현재 제품명, 가격, 소개 글, 연락처는 자연스러운 임시 문구입니다.

# 러브컨츄리

뜨개 DIY 키트 브랜드 **러브컨츄리**의 반응형 한국어 홈페이지입니다.

## 실행

빌드 도구가 필요 없습니다. `index.html`을 브라우저에서 열거나 간단한 정적 서버로 확인하세요.

```sh
python3 -m http.server 8000
```

## 구성

- `index.html` — 홈과 대표 제품 3개
- `about.html` — 브랜드를 시작한 사람의 이야기
- `products.html` — 전체 제품 목록
- `products.json` — 제품명, 가격, 이미지 주소, 구매 링크 데이터
- `styles.css` — 반응형 디자인과 접근성 스타일
- `script.js` — 모바일 메뉴, 스크롤 효과, 제품 목록 불러오기
- `assets/` — 사이트 이미지

## 제품 추가하기

제품 목록은 `products.json` 한 곳에서 관리합니다. `products` 배열의 마지막 항목 뒤에 쉼표를 넣고 아래 형식의 제품을 추가하면 제품 페이지에 자동으로 표시됩니다. 홈에는 배열 앞쪽의 제품 3개가 대표 제품으로 표시됩니다.

```json
{
  "name": "제품명",
  "price": 10000,
  "image": "https://이미지-주소",
  "url": "https://구매-링크"
}
```

가격은 쉼표와 `원`을 제외한 숫자로 입력하세요. 사이트에서 자동으로 `10,000원`처럼 표시합니다.
